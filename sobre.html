📖 Sobre o Projeto

A Lumina Books Procurement Analytics é uma solução fictícia desenvolvida por Stephany Gonçalves da Silva para demonstrar competências em análise de dados, Procurement, estoque e gestão de fornecedores.

🎯

O desafio

Equilibrar disponibilidade de livros, investimento em estoque, custos de aquisição e desempenho dos fornecedores.

O objetivo é reduzir riscos de ruptura sem gerar excesso de estoque e capital parado.

💡

A solução

Um portal de Procurement Analytics que integra dados de vendas, compras, estoque, catálogo e fornecedores.

Os dados são transformados em KPIs, gráficos e recomendações para apoiar a tomada de decisão.

📊

Análises

Receita, vendas, gastos, estoque, giro de produtos, custos e desempenho dos fornecedores.

O projeto também utiliza conceitos de Curva ABC e concentração de compras.

🧠

Apoio à decisão

O histórico de vendas e a situação do estoque são utilizados para estimar necessidades de reposição.

Os títulos recebem prioridades para orientar decisões de compra.

💼

Competências demonstradas

Procurement Análise de Dados Compras Gestão de Estoque Fornecedores Análise de Custos KPIs Curva ABC Dashboards Tomada de Decisão
🛠️

Tecnologias utilizadas

HTML5 CSS3 JavaScript Chart.js CSV GitHub GitHub Pages
⚠️

Projeto fictício

Todos os nomes de livros, fornecedores, valores, vendas, compras, estoques e indicadores apresentados neste projeto são fictícios e foram criados exclusivamente para fins educacionais e de portfólio.
